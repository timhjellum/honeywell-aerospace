Honeywell Aerospace · Ordering Tablet UI

Many systems.
One interface.
Built to scale.

Honeywell's ordering systems lived across a patchwork of legacy web front‑ends — none of them built for a tablet. My job was to convert those systems into one scalable interface: standardized, reusable, and ready for whatever Honeywell builds next.

The Challenge

Honeywell's web‑based ordering systems had been built over years, across teams, on a patchwork of different front‑end technologies — none of them designed for a tablet. Every retrofit meant reinventing the interface from scratch. I led the UX for converting those systems to tablet specifications: consolidating fragmented front‑ends into one scalable, universal solution that could be retrofitted into what already existed, and reused in everything built after.

My Role

Standardizing the interface, system by system.

User Experience (UX) Designer Interactive Designer (ID) User Interface (UI) Developer
